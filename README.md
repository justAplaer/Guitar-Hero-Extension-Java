# Guitar-Hero-Extension-Java
The following project is insipred by my course work on java courses. It bridges inheritance, Java structured and interface to create a program that immitates behavior of a guitar

After completing my Java II coursework, I independently extended a Guitar Hero-style keyboard instrument project far beyond its original 37-key implementation. Using maps and object-oriented design, I added customizable key mappings, per-key frequency adjustment, independent guitar layouts, layout switching and deletion, and per-layout key-press statistics.
Each layout maintains its own configuration, for example, the A key can play at 300 Hz in one layout and 400 Hz in another, without affecting the rest. This roughly 1,000-line extension was built over about a week of focused development and includes JavaDoc documentation for the project’s methods and classes.
